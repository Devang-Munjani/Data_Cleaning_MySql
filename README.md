# Data_Cleaning_MySql

Data Cleaning Project
Data Cleaning Project
This project involves cleaning and preparing the World Layoff dataset using mySQL to ensure the data is accurate, consistent, and ready for analysis. The cleaning process follows a structured four-step approach commonly used in real-world data preprocessing tasks.

1. Removed duplicate records
2. Standardized inconsistent data
3. Handled null or blank values
4. Dropped unnecessary rows and columns
